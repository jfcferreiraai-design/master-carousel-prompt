# Clean Insight

## Role

This file defines the Clean Insight design layer only.

It should be applied on top of the shared Project Instructions base.
It should not redefine shared runtime behavior such as modes, preview frame rules, export rules, PT-PT rules, or HTML safety rules.

## Design Intent

Clean Insight is for educational, problem-solution, transformation, and explanation-heavy carousels with the clearest reading experience.

It should feel polished, calm, structured, and easier to read than Overlay Hook.

## Cover Treatment

- Prefer a clear text-led cover or a lightly supported image.
- Use calmer backgrounds, soft panels, subtle gradients, or diagram-like structure.
- If an image exists, treat it as support rather than a dominant full-bleed hero.
- Never let the cover feel empty, generic, or visually loud.

## Typography Direction

- Prioritize pairings that feel clean, readable, structured, and calm.
- Use typography to guide reading order before decoration.
- Headings should feel clear and confident rather than dramatic.

## Title Placement And Scale

- Place the main hook in the upper-middle or middle area for faster reading.
- Keep the title dominant, but calmer and more structured than Overlay Hook.
- A short framing line or label can be used when it improves clarity.

## Image Expectation Behavior

- Images are optional, not required.
- Screenshots, simple diagrams, or small supporting visuals are acceptable.
- The variant must work as a text-led carousel without looking empty.

## Hierarchy

- Each slide should feel like one clear idea, step, or explanation block.
- Structure should be immediately legible.
- Visual design should support understanding, not compete with it.

## Spacing

- Use generous, even spacing and clearer group separation.
- Prefer calmer density than Overlay Hook.
- Keep lists, cards, and text blocks aligned and easy to scan.

## Component Style

- Prefer clean cards, dividers, numbered rows, and structured callouts.
- Components should feel elegant and functional rather than dramatic.
- Decorative styling should stay subtle.

## Slide Sequence Emphasis

- Best for problem -> explanation -> solution -> steps -> outcome.
- Favor instructional progression over editorial drama.
- Let the middle slides do clear teaching work.

## CTA Tone

- Keep the CTA practical and low-pressure.
- Good directions: save this, try this, apply this, use this, follow for more.
- Avoid dramatic closing energy or hard-sell pressure.

## Boundary

If the slides stop feeling structured and explanation-friendly, the output is drifting away from Clean Insight.
