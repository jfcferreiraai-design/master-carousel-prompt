# Overlay Hook

## Role

This file defines the Overlay Hook design layer only.

It should be applied on top of the shared Project Instructions base.
It should not redefine shared runtime behavior such as modes, preview frame rules, export rules, PT-PT rules, or HTML safety rules.

## Design Intent

Overlay Hook is for informative, opinion-led, trend, and commentary carousels with a strong editorial cover.

Slide 1 should do the heaviest visual lifting.
Slides 2+ should convert that attention into sharp, structured insight.

## Cover Treatment

- Prefer an image-led or image-like cover.
- Use full-bleed or near full-bleed treatment when an image exists.
- Protect readability with a dark lower fade or gradient overlay.
- If no image exists, use a strong CSS or lightweight SVG fallback with atmosphere, glow, shape, texture, or tonal layering.
- Never let the cover feel blank, placeholder-like, or generic.

## Title Placement And Scale

- Place the main hook in the lower half or lower-middle area of the cover.
- Make the main hook dominant and instantly legible.
- Keep the title visually larger and more assertive than on the supporting slides.
- Any label or tag should stay secondary.

## Image Expectation Behavior

- Overlay Hook is strongest when a cover image is available.
- It must still work without one by using a premium editorial fallback treatment.
- Supporting images are optional, not required.
- Supporting slides should not become image-dependent.

## Hierarchy

- Slide 1 should feel like a premium editorial or news cover.
- Slides 2+ should feel cleaner, calmer, and more readable than the cover.
- Each slide should carry one dominant idea.
- Contrast and emphasis should soften after the cover without losing polish.

## Supporting Slide Feel

- Sharp
- Structured
- Scan-friendly
- Premium
- Restrained rather than cluttered

Avoid:
- long feature lists
- essay blocks
- heavy step-by-step tutorial energy
- generic educational template feel

## Preferred Story Arc

Preferred default sequence:
1. Hook cover
2. Why this matters
3. Key insight 1
4. Key insight 2
5. Key insight 3 or example
6. Takeaway
7. CTA

Six slides are acceptable if the topic is tighter.

## CTA Tone

- Keep the CTA light by default.
- Good CTA directions: save, share, follow, comment, want more like this.
- Do not turn the ending into a hard conversion push unless the user explicitly asks for it.

## Boundary

If Slide 1 stops feeling image-led and scroll-stopping, the output is drifting away from Overlay Hook.
