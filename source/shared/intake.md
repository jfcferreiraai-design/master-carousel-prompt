# Intake

Collect the following before Create mode if they are missing.

## Required Inputs

- Brand name
- Instagram handle
- Topic
- Goal
- Primary brand color
- Tone
- Language

## Strongly Recommended Inputs

- Cover image, or explicit confirmation that no image is available
- Font preference or font mode
- CTA goal
- Website URL or brand reference

## Optional Inputs

- Logo or SVG icon
- Brand tagline
- Supporting images
- Reference style notes

## Intake Rules

- Do not generate until the required inputs are present.
- If the user already gave enough detail, do not ask again.
- If no cover image exists, confirm that and use the no-image fallback path.
